📖 术语表：Agent 上下文管理

本课程所有章节共用这套名词。遇到不认识的词，先来这里查。

术语一句话定义类比
Context Window
上下文窗口		 模型单次推理能"看到"的 token 总量上限。固定大小、按 token 计费。 一个固定容量、很贵的"展示桶"
Raw Log
原始日志		 append-only 事件流，完整记录"发生过什么"。可回放、可审计。压缩不改它。 监控录像（全量保存）
Surface
表面投影		 模型"现在应该看到"的那一份历史，是 Raw Log 的投影（视图）。压缩 = 改它。 当下正在看的屏幕（可切）
Event Sourcing
事件溯源		 状态由"追加的事件序列"派生，而非直接改状态。DeepHarness 的基石。 记账用流水，不用余额覆盖
Lazy Degradation
懒惰降级		 永远先试最便宜的压缩手段，逐级升级，LLM 摘要是最后手段。 先关灯省电，不行再关空调
Compaction
压缩		 把一段旧对话摘要成一条，从 Surface 移出原文。DeepHarness 中靠追加事件实现。 把一摞旧笔记缩成一张摘要卡
Spill
外置		 工具结果超阈值时存盘，上下文只留 head/tail 预览 + locator（定位符）。 大文件存 U 盘，桌面只放快捷方式
Shadowed
遮蔽		 被摘要替换掉的原文不删，只是"不进 Surface"。压缩可逆的关键。 笔记收进抽屉，没扔
Token Meter
计量器		 回放快照，按 Surface 位置计算每个节点的 token 数。压缩决策的唯一压力来源。 实时水位计
Prompt Cache
提示缓存		 相同前缀可复用 KV cache，享折扣。Claude Code 为此把 CLAUDE.md 踢出 system prompt。 公共前缀的"团购折扣"
Locator
定位符		 spill 后留在上下文里的"去哪读全文"的指针（路径 + 预览）。 文件快捷方式
Shadowed Range 被压缩区间在 Surface 里的位置跨度（非数值 seq 区间，start 可能 > end）。 抽屉里那一格的范围
