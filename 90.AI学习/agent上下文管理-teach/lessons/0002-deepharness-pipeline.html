3. 决策树（"怎么做"的灵魂）

整条流水线的核心逻辑，用一张图说清：

一句话记住决策树：先免费剪枝 → 重算 → 够就停（不调模型）→ 不够才选段调 LLM → 校验收敛 → 写回投影。 绝大多数情况在"免费剪枝"后就停了，几乎零成本。

4. 事务锁：防止两个压缩并发改同一 Surface

压缩是"读 Surface → 生成摘要 → 改 Surface"的多步操作，必须原子。DeepHarness 用三条 log-only 事件当锁：

  • 中途崩溃 → 留下"有 start 无 end"的遗留锁 → 阻塞所有入口点（任何新操作先检查遗留锁）。保证不会两个压缩同时改同一 Surface。
  • 手动压缩有 6 类预期失败（busy / cancelled / changed / summary / commit / persistence）：失败被当一等公民记录，每种都定义 Surface 影响与日志影响。

6. 你要怎么实现：最小 CompactionEngine 伪代码

把上面所有概念收成一个可运行的骨架（TypeScript 风格）。重点看注释里的"对应哪一节"：

interface Surface { nodes: Node[] }            // 模型看到的历史
interface RawLog { events: Event[] }           // 全量事件，只增不减

class CompactionEngine {
  constructor(private meter: TokenMeter, private llm: Summarizer) {}

  // §2 触发入口
  compactIfNeeded(surface: Surface, raw: RawLog): void {
    if (!this.meter.overThreshold(surface)) return;   // pressure/overflow

    // §3 ② 先免费剪枝（不调模型）
    const pruned = toolResultPruner(surface);
    if (!this.meter.overThreshold(pruned)) {
      this.commit(pruned, raw);                        // ③ 够就停，不调 LLM
      return;
    }

    // §3 ④ 不够才选段 + 调 LLM
    const range = selectCompactableRange(pruned);      // 留尾部 + 不切工具对
    const summary = this.llm.summarize(range);         // 上 LLM（贵·有损）
    if (this.meter.tokensOf(summary) >= this.meter.tokensOf(range)) {
      throw new Error('未收敛：摘要不比原文小');          // §3 校验收敛
    }

    // §4 + §5 事务锁 + 写回投影（Raw Log 不动）
    raw.events.push({ type: 'compaction/start', range });
    raw.events.push({ type: 'compaction/summary', text: summary });
    surface.replace(range, summaryNode);               // surfaceOp.replace
    raw.events.push({ type: 'compaction/end' });
  }

  private commit(s: Surface, raw: RawLog) { /* 推进 surface，追加日志 */ }
}

// §1 压力唯一来源：所有判断读这一个单例
class TokenMeter {
  measure(surface: Surface): Measurement { /* 按 surface 位置计价 */ }
  overThreshold(s: Surface): boolean { return this.measure(s).total > LIMIT; }
}

对照 Lesson 0001 的"三类操作"：toolResultPruner 属 ① 压缩、spill（超大结果外置）属 ②、注入时裁剪属 ③。决策树就是 compactIfNeeded 的 if/else。
