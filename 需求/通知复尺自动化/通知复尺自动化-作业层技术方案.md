```JSON
{
  "messageId": "MSG202608140001",
  "operateTime": "2026-08-14 14:30:25",
  "tasks": [
    {
      "taskDispatchNodeId": "1002657855581",
      "projectId": 100001,
      "projectAddress": "上海市浦东新区XX路XX号",
      "materialCode": "029001001",
      "materialName": "集成吊顶",
      "supplierName": "XX供应商",
      "taskName": "通知复尺",
      "recommendVisitTime": "2026-08-16 00:00:00",
      "notify": true
    },
    {
      "taskDispatchNodeId": "1002657855582",
      "projectId": 100002,
      "projectAddress": "上海市浦东新区XX路XX号",
      "materialCode": "029002001",
      "materialName": "橱柜",
      "supplierName": "XX橱柜供应商",
      "taskName": "通知复尺",
      "recommendVisitTime": "2026-08-17 00:00:00",
      "notify": false
    }
  ]
}
```

其中：

- `notify = true`：用户当次操作选择了该任务并执行通知。
    
- `notify = false`：用户当次操作未选择该任务。
    
- `tasks` **记录本次操作涉及的全部任务，而不仅仅是实际执行成功的任务**。
    
- `operateTime` 为用户点击「一键通知」时的操作时间。
