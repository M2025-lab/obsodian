⑥ 字段对照 排障时对着改

resolved
status=1 已解决 / status=0 未解决；后端在未解决时把 resolveTime 置 null（遮掉 1970 哨兵值），前端不再需要判
questionTypeName
type 1橱柜/定制柜进度 2主材整改 3主材进度 4云助理取消 5其他
senderName
首问发送人＝项目经理（三锚定位的锚2），闭环回复里的「提问人」就是他
messageId
小师父异步任务标识——排障时拿它去小师父后台查 Agent 全过程（模型/工具编排在它那边）
pushItems
issue-reply-push 独有：单群一条（groupId/success/traceId/errMsg），success=false 时看 errMsg；空数组=回复为空或 issue 无来源群，推送被跳过（后端日志有原因）
list / hasMore
issue-list 返回 IssueListPageVO：list 行字段与详情同口径（type 映射名/品类/业主/解决状态），点行即渲染详情卡——从列表挑 issueId 去 curl reply/reply-push

本页纯本地渲染：无出网、无 moma runtime 授权、粘贴即显。后端代码：eden-agenda MsgAnalyzeService（issueDetail / reply / replyAndPush 三个方法，reply 走小师父 Agent 服务，replyAndPush 再把回复推回原群）。
