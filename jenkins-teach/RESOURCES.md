# Jenkins Resources

## Knowledge

- [官方文档：Pipeline 总览（jenkins.io/doc/book/pipeline）](https://www.jenkins.io/doc/book/pipeline/)
  权威的 Pipeline 概念与骨架（声明式 vs 脚本式）。Use for：搞清 pipeline / agent / stages / steps 的层级关系。
- [官方文档：使用 Jenkinsfile（jenkins.io/doc/book/pipeline/jenkinsfile）](https://www.jenkins.io/doc/book/pipeline/jenkinsfile)
  Jenkinsfile 写法、环境变量、凭据、参数、错误处理。Use for：把真实命令搬进 Jenkinsfile 的标准写法。
- [官方文档：Pipeline 语法参考（jenkins.io/doc/book/pipeline/syntax）](https://www.jenkins.io/doc/book/pipeline/syntax/)
  agent / options / environment / parameters / post 等指令的参数清单。Use for：写 Jenkinsfile 时查某个指令的可用参数。
- [官方快速上手：Creating your first Pipeline（jenkins.io/doc/pipeline/tour/hello-world）](https://www.jenkins.io/doc/pipeline/tour/hello-world/)
  含各语言的最小 Jenkinsfile 示例（Java/Maven 的 docker agent 示例）。Use for：照抄第一个能跑的 Java 流水线。
- [官方：安装 Jenkins（jenkins.io/doc/book/installing）](https://www.jenkins.io/doc/book/installing/)
  各平台（Docker / War / Linux / macOS）安装方式，含 Java 版本要求。Use for：本地把 Jenkins 跑起来那一课。
- [Declarative Directive Generator（Jenkins 内置）](https://www.jenkins.io/doc/book/pipeline/getting-started/)
  在已装好的 Jenkins 里，"Pipeline Syntax" 页面可图形化生成声明式片段。Use for：不会写某个指令时自动生成代码。
