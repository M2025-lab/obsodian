Jenkins 从零到一 · 第二课

安装 Jenkins，跑通你的第一次 Maven 构建

今天的可验证胜利：浏览器打开 localhost:8080，点一下 Build，控制台出现 BUILD SUCCESS，workspace 里出现 target/*.jar。

上节课你已经在脑子里把"构建"拆解清楚了。这节课把它落成真东西。你本机**没有 Docker、只有 Java 8**，所以全程走 macOS 的 brew 路线——而且 brew 会顺手把 Jenkins 要的 JDK 21 也装上。

1. 先钉死"两套 JVM"（这是本节课的地基）

一句话：Jenkins 用 JDK 21 只是"它能启动"；真正编译你代码的是 ./mvnw，它按 pom.xml 里的 java.version=1.8 把字节码打成 Java 8。所以你机器上的 Java 8（Corretto）和 brew 装的 openjdk@21 能共存，谁也不碍谁。

2. 安装并启动（macOS，命令已核实）

# 1) 装 Jenkins LTS（会顺带装 openjdk@21 作为依赖）
brew install jenkins-lts

# 2) 以后台服务启动，开机自启，默认端口 8080
brew services start jenkins-lts

如果你不想让它开机自启、只想临时跑一下，用前台模式（终端关了就停）：

/opt/homebrew/opt/openjdk@21/bin/java \
  -jar /opt/homebrew/opt/jenkins-lts/libexec/jenkins.war \
  --httpListenAddress=127.0.0.1 --httpPort=8080
  • JENKINS_HOME（所有配置/插件/构建数据）默认在 ~/.jenkins，即 /Users/mirror/.jenkins。
  • 启动后等约 10 秒，浏览器开 http://127.0.0.1:8080。

3. 解锁与初始化

  1. 首屏要求管理员密码，从本地文件读（命令直接复制）： 
    cat ~/.jenkins/secrets/initialAdminPassword
    把输出的那串字符粘进网页。
  2. 选 "Install suggested plugins"（装推荐插件，等几分钟，含 Git、Pipeline 等）。
  3. 创建管理员账号（记好用户名密码）。
  4. 实例地址保持 http://127.0.0.1:8080，点 "Save and Finish"。
装插件这一步必须联网。公司内网如果拉不到 Jenkins 官方更新中心，会卡住——那时再问我，有离线方案。

4. 先跑一个 Hello World，确认 Jenkins 活着

别一上来就编译大项目。先建个最小流水线证明"它能跑"：

  • 左侧 New Item → 名字填 hello → 选 Pipeline → OK。
  • 下滑到 Pipeline 段，Definition 选 Pipeline script，把下面的脚本粘进去：
pipeline {
  agent any
  stages {
    stage('Say Hi') {
      steps { echo 'Jenkins 活了！' }
    }
  }
}
  • 点 Save → 左侧 Build Now → 点最新的 #1 → Console Output 看到 Jenkins 活了！ 和蓝点即成功。

5. 跑通真正的 Maven 构建（接你的项目）

现在把第一课的 Jenkinsfile 落进你的工程根目录（这就是"Pipeline as Code"）。把下面内容存成 edar-starlord/Jenkinsfile：

// edar-starlord/Jenkinsfile（声明式；用 mvnw，无需另装 Maven）
pipeline {
  agent any
  stages {
    stage('Build') {
      steps {
        // 用 wrapper，避免机器上没装 Maven / PATH 问题
        sh './mvnw -o clean package -Dmaven.test.skip=true'
      }
    }
    stage('Package') {
      steps {
        sh 'mkdir -p release/lib'
        sh 'cp edar-starlord-web/target/*.jar release/lib/'
        sh 'tar czvf release.tar.gz release'
        archiveArtifacts artifacts: 'release.tar.gz', fingerprint: true
      }
    }
  }
}

然后新建任务接 Git（用本地仓库路径，Jenkins 和你同机，最省事）：

  • New Item → edar-build → Pipeline → OK。
  • Definition 选 Pipeline script from SCM。
  • SCM 选 Git，Repository URL 填 file:///Users/mirror/IdeaProjects/edar-starlord（本地路径要加 file:// 前缀）。
  • Branch 填 */master（或你当前分支）。
  • Script Path 填 Jenkinsfile（就是上一步那个文件）。
  • Save → Build Now → 看 #1 控制台。
成功标志：控制台最后一行 BUILD SUCCESS，且 ~/.jenkins/workspace/edar-build/edar-starlord-web/target/ 下出现了 *.jar。你亲手把 build.sh 自动化了。

6. 三个高频坑（先看过，省得卡）

  • mvnw 没执行权限：终端跑 chmod +x /Users/mirror/IdeaProjects/edar-starlord/mvnw。
  • 控制台报 Java 版本相关警告：Jenkins 用 JDK 21 跑 ./mvnw 编译 Java 8 目标，demo 能过。若要严格"在 Java 8 上构建"，正确做法是 Jenkins Global Tool Configuration 里加一个 JDK 8 工具，再在 Jenkinsfile 写 tools { jdk 'jdk8' }——这是进阶点，先知道有这回事。
  • workspace 在哪：~/.jenkins/workspace/<任务名>/，所有代码和产出都在这里，出问题先来这看。

7. 本课小练习

练习 A（必做）：执行第 2 节命令，浏览器打开解锁页，截一张图（或把密码文件路径记下来）。
练习 B（核心胜利）：完成第 4 节 hello + 第 5 节真构建，确认控制台 BUILD SUCCESS 且 target/*.jar 生成。
练习 C（进阶，选做）：把 -Dmaven.test.skip=true 去掉，再加一个 stage('Test') 跑 ./mvnw test——体会"真 CI"和"只打包"的区别。

8. 检索练习

凭记忆答，答完点"看答案"。

① 你机器上 Jenkins 2.568 主程序跑在哪个 JDK？

答案是 Java 21。Java 8 只是你项目的编译目标，跟 Jenkins 自己跑哪个 JDK 无关。

② 首次解锁的管理员密码文件在哪？

答案是 ~/.jenkins/secrets/initialAdminPassword（macOS brew 默认 JENKINS_HOME 是 ~/.jenkins）。

③ 为什么本课 Jenkinsfile 用 ./mvnw 而不是 mvn？

答案是 wrapper 不依赖本机 Maven。Jenkins 跑构建的 shell 环境 PATH 不一定有 mvn，而 mvnw 自带，最稳。
