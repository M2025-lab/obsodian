- 均为 Java + Spring Boot + Maven 多模块,贝壳/链家系(ke.com / lianjia.com)。

- 配置中心:Apollo(参见 `📚 Apollo配置JSON注入Map启动失败.md`、`📚 starlord Kafka消息接入配置手册.md`)。
- 构建:根目录 `build.sh` / `build-dayu.sh` + Dockerfile。
