# 21. SyncMaterialTaskService#syncAssessmentTime —— 考核时间回写 starlord

## 一、功能是什么

把 workbench 算出的**考核（应完成）时间**回写到 starlord 主材任务上（`directSaveEstimatedTime` 直写预估时间）。这是「排程侧任务面板显示的考核时间」的数据来源之一。由 16 号文档在 `syncMaterialTask` 开关（= 项目 inSchedule）或 mode=7 时、经 `rpcAsyncExecutor` 线程池**异步**调用。

## 二、逻辑实现

```java
public void syncAssessmentTime(ScheduleOrderNode orderNode, ScheduleDispatchNode dispatchNode, Date assessmentTime) {
    MaterialTaskEstimatedTimeChangeParam param = new MaterialTaskEstimatedTimeChangeParam();
    if (orderNode != null && fulfillmentTaskToMaterialTaskType.containsKey(orderNode.getTaskType())) {
        // 货单任务 → starlord 任务类型映射（taskType + nodeType 两级）
        param.setProjectOrderId(...); param.setOrderNo(...); param.setMaterialCode(categoryId);
        param.setSupplierCode(fulfillmentDeliveryId);
    }
    if (dispatchNode != null) {
        param.setNodeId(dispatchNode.getNodeId());   // 用工任务直接定位到节点
    }
    param.setEstimatedTime(assessmentTime);
    try {
        edarStarlordRpc.directSaveEstimatedTime(param);
    } catch (RpcException e) {
        LOGGER.error("error in syncAssessmentTime ...", ...);   // 吞异常——异步线程不能向上抛
    }
}
```

**`fulfillmentTaskToMaterialTaskType` 静态映射**（workbench 货单 taskType → [starlord taskType, nodeType]）：

| 货单任务 | starlord 映射 |
|---|---|
| 设计审核 DESIGN_REVIEW | DESIGN_REVIEW + START |
| 下单 PLACE_ORDER | ORDER + START |
| 接单 TAKE_ORDER | ORDER_TAKING + START |
| 备货 STOCKING | STOCK_UP + START |
| 入仓 STOCK_IN | WAREHOUSE_ENTER + START |
| 通知送货 NOTICE_READY_TO_DELIVERY | ENTER + NOTIFY_CAN_START |
| 送达 DELIVERY_GOODS | ENTER + START |
| 签收 READY_TO_SIGN | ENTER + FINISH_START |

映射表在本类和 16 号文档的 `sendAssessmentMessage`（排程 Kafka 消息）两处共用——保证「回写 starlord」和「通知排程」用同一套类型语义。

## 五、备注

- **异步 + 吞异常**：`rpcAsyncExecutor.execute` 提交，RpcException 在异步线程内 catch 记日志——刷数接口返回 success 不代表 starlord 回写成功，要核对日志「error in syncAssessmentTime」。
- 货单分支只处理映射表里的 8 类任务；不在表里的（理论上不会出现在考核链路）静默不回写。
- 用工分支只带 `nodeId`——starlord 侧按节点定位，不带品类供应商等冗余。
- 本类还有大量其他方法（同步主材任务全流程 syncMaterialTask 等）服务于别的链路，本文件夹只覆盖 `syncAssessmentTime`。
