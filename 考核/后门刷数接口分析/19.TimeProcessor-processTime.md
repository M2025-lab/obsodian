# 19. TimeProcessor#processTime —— 时间推算纯函数

## 一、功能是什么

整条链路里唯一做「日期算术」的地方：给定基准时间 + 关系词 + 间隔天数，算出目标日期，途中**跳过指定的节假日**。应开始/应完成时间的最后一步都经它。

## 二、逻辑实现

```java
public static Date processTime(String timeRef, BigDecimal interval, Date realCompTime, Integer skipBitmask, Map<LocalDateTime, Integer> calendars) {
    BigDecimal interVal = determineInterval(timeRef, interval);          // 关系词 → 带符号间隔
    LocalDateTime expectCompDateTime = RuleUnit.figureAssessmentTime(
            DateUtil.date2LocalDateTime(realCompTime), interVal.intValue(), skipBitmask, calendars);
    return DateUtil.localDateTime2Date(expectCompDateTime);
}

private static BigDecimal determineInterval(String timeRef, BigDecimal interval) {
    switch (timeRef) {
        case "当天": return 0;                       // 当天 = +0
        case "之前": return interval.multiply(-1);    // 之前 = 负向
        case "之后": return interval;                 // 之后 = 正向
        default: throw new RuntimeException("不支持的时间关系: " + timeRef);
    }
}
```

`RuleUnit.figureAssessmentTime(start, n, skipBitmask, calendars)`（引擎包内的位移算法）：从 start 逐日推进 n 天，每一天检查 `calendars[date] & skipBitmask != 0` 则不计入——即「**自然日推进但假期顺延**」的混合口径：

- `skipBitmask = CALENDAR_DAY_BITMASK`（公司春节+法定春节）：基本按自然日，仅春节顺延；
- `skipBitmask = indicatorHolidayMap[指标名]`（工作日口径，如全部节日+双休）：接近工作日推算。

## 三、调用了谁 / 为什么

| 被调方法 | 为什么调用 | 一句话简介 |
|---|---|---|
| `RuleUnit.figureAssessmentTime` | 真正的逐日位移+跳假期算法 | write.engine.meta 下的静态工具〔纯函数〕 |
| `DateUtil.date2LocalDateTime` 等 | Date↔LocalDateTime 转换 | 〔纯函数〕 |

无 IO——叶子纯函数。

## 四、下钻终点

- 〔纯函数〕`TimeProcessor` + `RuleUnit.figureAssessmentTime` + `DateUtil`。

## 五、备注

- **入参 interval 是 BigDecimal**：规则模板里的 duration 字符串直接 `new BigDecimal(ruleCfg.getDuration())`，若模板配了小数天（如 0.5）会在 `interVal.intValue()` 处截断为 0——配规则时用整数天。
- 三个关系词硬编码中文，模板侧若传英文枚举值会直接 RuntimeException——`TIME_REF_MAP`（06 号文档）在 rebuild 时已把 BEFORE/AFTER/CURRENT 翻译成中文，此处是第二道翻译终点。
- 该函数被三处复用：expectStartTime（前置±间隔）、expectEndTime（+任务耗时）、汰换缓冲（replaceDate+N 自然日，skipBitmask 固定 CALENDAR_DAY_BITMASK）。
- 详细节假日体系（bitmask 枚举/四年缓存/指标名→bitmask 映射）见 [[15.HolidayService]]，本函数只管位移。
